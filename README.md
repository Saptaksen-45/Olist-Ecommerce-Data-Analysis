# 📊 Olist E-commerce Analysis Project
**End-to-End Business Intelligence Project**

## 🎯 Overview
This project analyzes **100,000+ orders** from Olist, a Brazilian e-commerce marketplace. The goal was to transform raw data into actionable business insights regarding sales trends, delivery performance, and customer geography.

## 🛠️ Tools & Technologies
- **Database:** SQL Server (T-SQL)
- **Visualization:** Power BI Desktop
- **Process:** ETL (Extract, Transform, Load)

## 🏗️ Project Workflow
1. **Data Cleaning (SQL):** - Filtered only 'delivered' orders to remove noise.
   - Handled NULL values in logistics timestamps.
   - Created a consolidated View for seamless Power BI integration.
2. **Data Modeling:** - Established a Star Schema connecting Customers, Orders, Products, and Payments.
3. **Dashboarding:** - Built interactive visuals for Revenue Trends, State-wise Sales, and Category Performance.

## 📈 Key Insights
- **Market Leader:** Sao Paulo (SP) is the highest revenue-generating state.
- **Volume:** Successfully analyzed ~96.5k unique delivered orders.
- **Logistics:** Identified key states with higher than average delivery delays.
